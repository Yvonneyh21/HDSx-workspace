
# Data Provenance and Stewardship Note

**Data Source:** I used the prepared NHANES Health Equity classroom dataset (`nhanes_equity_v6.csv`).

**Original Source:** The dataset was derived from public-use NHANES data provided by the CDC.

**Access Method:** I accessed the CSV file from the course repository using a relative file path in GitHub Codespaces.

**Classroom-use Boundary:** I used the data for unweighted descriptive analysis, not for causal inference or population estimates.

**Privacy Caution:** I should avoid uploading row-level data to external AI tools or attempting to identify individuals from the dataset.
